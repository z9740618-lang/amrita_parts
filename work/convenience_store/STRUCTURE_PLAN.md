# 分割構造計画 — アムリタ（コンビニ制服）

## 対象・動作仕様
- 原画：`source/convenience_store/base.png`（3840×3840、RGBA8、背景透明）
- 差分：`eyes_closed.png`（目閉じ）、`mouth_open.png`（口開き）。どちらも絵全体が描き直されていて、基本の絵から約1px右・0.3〜0.6px下にずれている。目と口の範囲だけ、1px以下の単位で位置を合わせて使う（`stage/alignment.json`）。
- 出力先：自作ツール puppet。Cubism の Import PSD は作らない（ユーザー指示）。
- 左右：キャラクター基準。`_r` はキャラの右で、画像では左側。
- 動かす動作（確定、可動量は未指定）：顔の向きXY、首の傾き、体の傾き、呼吸、目の開閉、笑い目、視線、眉の上下、口の開閉、口の形、頬の赤み、前髪・横髪・後ろ髪・お団子・髪リボンの揺れ。

## 主運動階層（設計図。リグ実装ではない）
```

    ├ hair_back ─ hair_bun_l ─ hair_ribbon_l（揺れ）
```

## 分割・統合の判断
| 部品 | 判断 | 理由 |
|---|---|---|
| 前髪 | 1枚の塊（房ごとに分けない） | 揺れは変形で足りる。房ごとに分ける要求がない |
| 横髪 | 左右で分ける | 前後関係（顔・耳・胴の前）が違い、それぞれ独立して揺れる |
| 後ろ髪 | 頭頂部・両側の編み込みを含めて1枚 | 顔の後ろで一緒に動く |
| お団子・リボン | 別パーツ | 独立して揺れる。リボンはお団子の下から出る |
| 眉 | 髪から分ける | 前髪の上に細い線で描かれている。上下に動かす |
| 瞳 | 瞳孔とハイライトも瞳と1枚 | 瞳と一緒に動くだけなので |
| 口 | 閉じ口（基本の絵）と、開き口3枚（上唇・下唇・口の中、差分から） | 口の開閉と形を表示切替と変形で表すため |
| 腕 | 胴体と1枚 | 腕を動かす要求がない |
| 頬 | 新しく描く（初期の濃さ0） | 元の絵に赤みがない。承認済み |

## 境界・線の持ち主
- 顔の輪郭線（茶色の線）は `face` の一部。顎の線より下の肌は `neck`。
- 髪の輪郭線（紺色の線）はその髪パーツ。髪と肌の境目の半透明部分（アンチエイリアス）は手前の髪側に持たせ、顔側はその下を描き足した。
- 眉：線の色だけを抽出。下にあった髪と肌は描き直した。眉を元の位置に重ねると原画と一致する。
- 鼻・閉じ口：周りの肌から透明度付きで抽出。下の肌は描き直した。
- 横髪が制服に重なる部分：制服が透けて見える半透明の房（特に画像左の白いシャツの上）は、髪と服の境界が画素だけでは決まらない。そのため手でなぞった範囲と色の規則で分けた。細かい断片が服側に少し残っている（既知の問題）。

## 描き足した隠れ領域（すべて「既定の姿勢で上のパーツに隠れている画素」だけに描いた）

| neck-under-chin | neck | 顎の下と襟の下 |
| eye-white-under-iris | eye_white_* | 瞳の下 |
